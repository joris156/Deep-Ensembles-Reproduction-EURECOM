# Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles

This repository contains the code to reproduce (some of) the results from the paper *Simple and Scalable Predictive Uncertainty Estimation using Deep Ensembles* (Lakshminarayanan et al., 2017).

## Project Structure
* `deep_ensembles_reproduction.ipynb`: Jupyter Notebook containing the data generation, PyTorch model implementation with Gaussian NLL loss, Deep Ensembles training loop, and uncertainty visualization.

## Requirements
* Python 3
* PyTorch
* NumPy
* Matplotlib
